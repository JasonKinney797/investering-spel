# Stonks Tycoon (Roblox)

A Roblox tycoon game based on the Investor Simulator web game.

1. **`GAME_DESIGN.md`**: the full concept: core loop, systems, numbers, UI, monetization, tech design.
2. **`SETUP.md`**: the one-time setup on Windows (Studio, Claude Code, Script Sync, MCP, skills, tools).
3. **`ROADMAP.md`**: 12 phases to build it, each with a ready-to-paste prompt for Claude and a test checklist.
4. **`CLAUDE.md`**: rules Claude Code follows automatically in this folder.

Start with `SETUP.md`, then follow `ROADMAP.md` from phase 1.
